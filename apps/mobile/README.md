# Prolific Mobile

Sprint 0 Flutter scaffold for the Prolific learner mobile application.

The current Flutter app contains the shared Android/Web learner presentation foundation, local lesson setup previews, a responsive Reading Player shell, and one bundled tutorial MP3 playback demonstration. Offline storage, synchronization, backend integration, authentication, production timing/alignment, and real Reading Session behavior are intentionally not implemented.

## Commands

Run these from the repository root:

```text
npm run dev:mobile
npm run analyze:mobile
npm run test:mobile
npm run format:mobile
```
